# 通用銷貨明細系統

小企業銷貨／請款單系統。介面區分「固定資訊」與「變動明細」，輸出為仿實體單據的視覺排版 Excel（銷貨單／請款單兩種，版面相同、僅標題不同），可載入舊檔二次編輯，並支援 A4／A5、直式／橫式列印（預設橫式）。打包為單一 Windows 執行檔（exe），免安裝、開箱即用。

## 技術架構

- 框架：Tauri 2（Rust 後端 + WebView2 前端），編譯後 exe 約 10–15MB
- 前端（看得到的）：HTML / CSS / 原生 JavaScript
  - 表單、明細 Grid、即時金額／稅額計算、必填驗證、下拉清單維護、列印
- 後端（看不到的）：Rust
  - Excel 讀寫（`umya-spreadsheet` 寫、`calamine` 讀）、單號計算、歷史紀錄、用系統預設程式開檔
- 無 Node 建置流程；前端為靜態檔，由 Tauri 直接載入

### 後端指令

| 指令 | 職責 |
|------|------|
| `save_excel` | 寫出「銷貨單」xlsx（仿 Example 版面） |
| `save_invoice` | 寫出「請款單」xlsx（與銷貨單同版面，僅標題不同） |
| `load_excel` | 讀舊檔 → 還原表頭與明細 |
| `next_seq` | 掃存檔資料夾內該類型當日檔案，回傳最小未使用流水號 |
| `append_history` | 追加一筆輸出紀錄（檔名、路徑、時間） |
| `read_history` | 讀回歷史清單 |
| `open_file` | 以系統預設程式（Excel）開啟歷史檔 |

`save_excel` 與 `save_invoice` 共用同一個 `write_form` 版面函式，只傳入不同標題。

## 資料欄位

### 表單區塊

- 單據：單號（自動編，見下）、出貨日期（預設今日）
- 我方（出貨方）：寶號、電話、傳真、地址（設定一次，自動記住）
- 客戶（到貨方）：客戶名稱、電話、送貨地址、業務員（印為「經辦人」）
- 明細（逐筆）：序號（自動）、品名（下拉）、單位（下拉）、數量、單價

### 計算

- 小計＝數量 × 單價（逐列）
- 銷貨總額＝各列小計加總
- 營業稅＝ROUND(銷貨總額 × 5%, 0)（整單一次，非逐列）
- 總計＝銷貨總額 + 營業稅
- 介面即時連動；Excel 內存為一般數值（無千分位格式，與 Example 一致）

### 單號規則（自動、分型別、可補空號）

- 格式：`出貨日 YYYYMMDD` + 三位流水號，例 `20260627001`
- 銷貨單與請款單**各自獨立計號**（依檔名前綴 `銷貨單_` / `請款單_` 區分）
- 流水號取「記住的存檔資料夾」內該類型當日檔案的**最小未使用號**：
  - 連號完整 → 接最大號 +1
  - 中間被刪（如刪掉 002）→ 下一張自動補回 002
- 須先存過一次（資料夾才會被記住）才能正確補號；不同資料夾各自獨立

## Excel 輸出格式（仿 Example 實體單據）

固定 7 列明細，採 Example.xls 的欄寬、列高、字體與框線。

```
列2  │ 客戶編號:(B:D) │      {寶號 22pt}(E:G 置中)      │ {我方地址 10pt}(H:J 靠右) │
列3  │                │      {標題 16pt}(E:G 置中)       │  TEL:.. FAX:..(H:J 靠右)  │
列4  │ 客戶名稱: {值C:E}                  │ 出貨日期:(I) {民國年 J}                   │
列5  │ 電　　話: {值C:E}                  │ 貨單編號:(I) {單號 J}                     │
列6  │ 地　　址: {值C:E}    發票:(F)       │ 收訖摘要:(I)              （列底細線分隔）  │
列7  │ 項目編號│ 品名規格(C:E) │數量│單價│小計│ 備註(I:J) │ ← 表頭
列8  │ 1～7 固定七列：序號、品名(C:E)、數量(含單位字串)、單價、小計、備註(I:J)
～14 │ ...（不足留空仍保框線；末列備註底為中線）...
列15 │ 經辦人:{值} │ 銷貨總額 {值} │ 營業稅 {值} │ 總計 {值,框中線} │
列16 │ 法律聲明（8pt 置中，整列細框）                                              │
```

### 字體（照 Example）

| 用途 | 字體 |
|------|------|
| 抬頭標籤、寶號、表頭 | 超研澤中圓 |
| 出貨日期／貨單編號／收訖摘要 | 華康中明體 |
| 明細數字、合計、聲明 | 新細明體 |
| 數量、備註 | 標楷體 |

超研澤中圓、華康中明體為商用字型；客戶端未安裝時 Excel 會自動替換系統字型，欄位位置不變、字體外觀略異。

### 民國年

出貨日期介面以西元 `YYYY-MM-DD` 輸入，輸出 Excel 時轉民國 `yyy/mm/dd`；載入舊檔時再轉回西元。

## 設定與資料儲存位置（打包成 exe 後仍可編輯品名／單位的原理）

關鍵：執行檔是「程式本體」（唯讀），而品名／單位清單等設定是「使用者資料」（可寫），兩者分開存放。清單不打包進 exe，而是執行時寫入使用者端的 WebView2 localStorage，因此安裝後按「編輯品項／編輯單位」即可隨時修改、即時生效、重開保留，完全不需重新打包。

```
打包後：程式本體（唯讀）與使用者資料（可寫）分離

C:\Program Files\通用銷貨明細系統\
└─ 通用銷貨明細系統.exe          ← 打包進去的程式本體（前端 HTML/JS/CSS + Rust 後端）
        │                          使用者不會也不該改動
        │  執行時讀寫 ↓（資料另存他處，故打包後仍可編輯清單）
        ▼
C:\Users\<使用者>\AppData\
├─ Local\com.example.salesform\EBWebView\Default\Local Storage\leveldb\
│     └─ localStorage  ← 「品名／單位清單」、我方資訊、上次存檔資料夾
│        由「編輯品項／編輯單位」按鈕即時寫入，重開程式仍保留
└─ Roaming\com.example.salesform\
      └─ history.jsonl   輸出歷史紀錄（檔名／路徑／時間，逐列追加）
```

| 資料 | 存放位置 | 寫入時機 |
|------|----------|----------|
| 品名／單位下拉清單 | `localStorage`（key：`list_items`、`list_units`） | 按「編輯品項／編輯單位」儲存時 |
| 我方寶號／電話／傳真／地址 | `localStorage` | 每次輸出時記住 |
| 上次存檔資料夾 | `localStorage`（key：`saveDir`） | 每次輸出後記住，下次預設同資料夾 |
| 輸出歷史 | `Roaming\com.example.salesform\history.jsonl` | 每次輸出追加一列 |

說明：

- 程式本體在 `Program Files`（唯讀，受系統保護）；清單若寫在程式裡，改動就得重新編譯打包。改放 `AppData`（使用者可寫）後，編輯在執行時即完成，與打包無關。
- localStorage 綁定「使用者帳號 + 本機 + 本程式」。換電腦、換 Windows 使用者帳號時清單不會跟著走，各自獨立；如需跨機共用需另做匯出／匯入（目前未實作）。
- 解除安裝程式不會清掉 `AppData` 內的清單與歷史；要完全清除需手動刪除上述資料夾。

## 開發與打包

需求：Rust 工具鏈、MSVC C++ 建置工具、Windows 內建 WebView2。

1. 安裝 Tauri CLI

   ```
   cargo install tauri-cli --version "^2" --locked
   ```

2. 開發模式（熱重載）

   ```
   cargo tauri dev
   ```

3. 打包 exe（產出於 `src-tauri/target/release/bundle/nsis/`）

   ```
   cargo tauri build
   ```

更換圖示：`cargo tauri icon path\to\logo.png`。

## 使用方式（給客戶）

App 內右上角「使用說明」按鈕亦有同樣步驟。

1. 我方資訊：填寶號、電話、傳真、地址，設定一次即可（輸出後自動記住）。
2. 客戶資訊：填客戶名稱（必填）、電話、送貨地址、業務員。
3. 明細：按「＋ 新增一項」。序號自動；品名、單位用下拉選單。
4. 維護清單：按「編輯品項／編輯單位」增刪下拉內容（每行一項，儲存即生效）。
5. 填數量、單價，可用 Tab 逐格移動；小計、營業稅、總計即時計算。
6. 輸出：按「輸出銷貨單」或「輸出請款單」，選存檔位置（記住上次資料夾），單號自動編。
7. 載入舊檔：選先前的 xlsx，自動還原表頭與明細，可續編後再輸出。
8. 列印：右下選紙張（A5／A4）與方向（預設橫式），按「列印」。
9. 歷史輸出：點清單中的檔名，直接以 Excel 開啟該檔。

## 注意事項

- 必填：單號、出貨日期、我方寶號、客戶名稱，且至少一列明細，每列品名、數量、單價不可空；未通過會在欄位旁顯示「此項必填」。
- 固定 7 列明細：單張最多 7 筆，超過不顯示。
- 載入舊檔依本系統的固定版面座標解析；外部來源 Excel 版面若不同無法正確讀回。
- 單號補空號依「記住的存檔資料夾」掃描，請固定存於同一資料夾以維持連號正確。
- 輸出時目標檔若正開在 Excel 中會寫檔失敗，請先關閉該檔。
